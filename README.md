# Self-Healing Intelligent Cloud System

An ML-based project that monitors system metrics, detects anomalies, and triggers automated healing actions.

> Currently under development.

## Features

* System metric monitoring
* Anomaly detection using Machine Learning
* Random Forest classification
* Automated healing workflow

## Tech Stack

* Python
* Pandas
* Scikit-learn
* Random Forest
* Joblib
* psutil

## Project Status

Currently working on improving anomaly detection and the automated healing process.
